# Sign-in
# 🔐 Protected Authentication Portal | Sicheres Benutzerportal

A lightweight and responsive frontend authentication system built with **Vanilla JavaScript**, **HTML5**, and **CSS3**. It demonstrates client-side data persistence, input validation, and secure session state handling using `localStorage`.

Ein leichtgewichtiges Benutzerportal mit Registrierung, Login-Validierung und Sitzungsverwaltung über den `localStorage`.

---

## ✨ Features | الميزات

* **Input Validation:** Real-time form checks for empty fields and valid 11-digit phone numbers.
* **Persistent Session:** Remembers the user's logged-in status even after closing or refreshing the browser.
* **Dynamic UI Toggle:** Smoothly transitions between the login form and the welcome dashboard.
* **Logout & Clear Data:** Fully resets the local session and brings back the authentication screen.
* **Clean & Responsive UI:** Modern layout formatted with CSS.

---

## 🛠️ Tech Stack | التقنيات المستخدمة

* **HTML5:** Form structure and structural elements.
* **CSS3:** Custom styling, layout management, and responsive visibility classes.
* **JavaScript (ES6):** DOM manipulation, `localStorage` API, dynamic timer timeouts, and event listeners.
